A single-line roast of the most boring appliance in the kitchen. The line starts from a detail everyone recognises: the fridge light only comes on when the door is open. The turn reframes it as an accomplice that appears only for the midnight crime.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program writes its one line to /output/entry.txt (override with MAKEFUN_OUTPUT_DIR).
